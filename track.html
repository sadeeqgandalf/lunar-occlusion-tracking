How to read the scores

ID kept: of the people tracked before going behind cover for 1–5 s, the share that got the same ID back. ID switches: times a person's ID changed. IDF1: identity consistency over the whole run (1 = perfect). MOTA: overall detection accuracy (misses, false tracks, switches).
