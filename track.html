Real-life version: like watching friends walk behind pillars in a mall. A good watcher remembers where each one was heading, so when someone steps out, they know who it is. The naive watcher forgets anyone they can't see, and greets them as a stranger.

Glossary

Every word on this page, in plain English
Detection guide ↗
One "I see something here" from the camera in one frame. It has a position but no name. Some are false alarms (dust, glare).
Track / ID (#12) guide ↗
The tracker's running record of one person over time, with a number. Keeping the same number for the same person is the whole job.
Occlusion guide ↗
Something blocks the camera's view of a person, here a boulder. They still exist; the camera just can't see them.
Coasting / hidden track guide ↗
While someone is hidden, the tracker keeps guessing where they are from how they were moving (the dashed shapes). The ellipse is how unsure it is: bigger = less sure.
ID kept / ID switch guide ↗
When the person reappears, did they get their old number back (kept ✔) or a new one (switch ✘)? A new number means the system now thinks there are two different people.
ID kept through occlusion (big %)
Of people who were tracked, then hidden for 1–5 seconds, the share that got their old ID back. Higher is better.
IDF1
How consistently each real person carried one ID over the whole run (0 to 1, higher is better).
MOTA
Overall accuracy: penalises missed people, false tracks and ID switches together (up to 1, higher is better).
GOSPA
One error number in metres that combines position error, missed people and false tracks (lower is better).
Naive / Aware / Aware + neg. info
Three versions of the same tracker that differ only in how they treat hiding. See the cards above.
